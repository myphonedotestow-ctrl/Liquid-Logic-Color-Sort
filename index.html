Local game data

The game stores your current puzzle, move history, elapsed time, level progress, daily challenge results, statistics and preferences in app-private storage on your device. These records are used only to run the game and restore your progress.

No online collection

This release has no accounts, advertising, analytics, purchases or backend service. It does not request internet access and does not send your game data to us or third parties. It does not access your contacts, location, camera, microphone or advertising identifier.

Retention and deletion

Local data remains until you clear the application's storage in Android Settings or uninstall the application. There is no server account or server copy to delete. Android cloud backup is disabled and the configured device-transfer rules exclude the application's stored data.

Sound and vibration

Sound preferences and the chosen palette are stored locally. Vibration is used only for game feedback and can be switched off.

Security

Game data is kept in Android's app-private storage. No app-controlled transmission of game data takes place. This policy describes the application itself, not independent services provided by Android, your device manufacturer or the app store.

Changes

If a future release adds online services, advertising or data collection, this policy and the store disclosures must be updated before that release.
